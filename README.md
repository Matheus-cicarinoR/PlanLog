# 🚜 TERRAFORTE PRO (RetroControl)

> Sistema web de alta performance para Gestão Operacional, Financeira, de Frotas e Telemetria de Retroescavadeiras e Maquinário Pesado.

---

## ⚡ Início Rápido

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```

## 🛠️ Stack Tecnológica

- **Frontend**: React 19, TypeScript, Vite
- **Roteamento**: React Router v7
- **Estilização**: Tailwind CSS v4, Lucide React, Base UI
- **Banco de Dados & Autenticação**: Supabase (PostgreSQL + RLS + GoTrue Auth)
- **Exportação de Documentos**: jsPDF, jsPDF AutoTable, html2canvas
- **Notificações**: Sonner Toasts
